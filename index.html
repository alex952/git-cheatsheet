Escenarios preconfigurados:
> Estado actual: En la rama "main". Haz un commit o crea una rama.
⚙️ Configuración Inicial
git config --global user.name "Tu Nombre"
Establece tu nombre global de autor. Esencial
git config --global user.email "tu@email.com"
Establece el email que aparecerá como autor de tus commits.
git init
Inicializa un repositorio Git local.
git clone <url>
Clona un repositorio remoto en tu máquina.
🔄 El Ciclo Diario
git status
Muestra el estado de los archivos en tu directorio de trabajo. Esencial
git add .
Prepara todos los archivos nuevos y modificados (del directorio actual) para el commit.
git commit -m "Mensaje explicativo"
Guarda la foto del código en el historial local.
🌿 Ramas (Branches)
git branch
Lista todas las ramas locales.
git switch -c <nombre-rama>
Crea y se cambia a una nueva rama.
git switch <nombre-rama>
Cambia a una rama existente.
git merge <rama>
Fusiona la rama especificada con la rama activa.
git rebase main
Reaplica los commits de la rama actual como commits nuevos sobre la punta de main. Reescribe historial
☁️ Sincronización Remota
git fetch
Obtiene los cambios del remoto sin alterar tu código local.
git pull
Descarga y fusiona los cambios remotos en tu rama actual.
git push -u origin <rama>
Sube tus commits locales al servidor remoto.
↩️ Deshacer y Guardar Temporalmente
git restore <archivo>
Descarta los cambios no preparados (fuera del staging) de un archivo. Cuidado
git restore --staged <archivo>
Saca un archivo del Staging Area sin perder cambios.
git stash
Guarda temporalmente en un cajón tus cambios sin confirmar.
git stash pop
Recupera los cambios guardados en el stash.
